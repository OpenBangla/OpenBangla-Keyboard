# OpenBangla Keyboard (OBK)

OpenBangla Keyboard is an open-source, Unicode-compliant Bangla input method designed for GNU/Linux, macOS, and Windows. It offers advanced automation features and supports popular keyboard layouts, including Avro Phonetic, Probhat, Munir Optima, and National (Jatiya).

Because it integrates key features from Avro Keyboard, transition for existing Avro users is both smooth and intuitive.

## Installation

> [!IMPORTANT]
> If you have an older version installed, please [uninstall](https://github.com/OpenBangla/OpenBangla-Keyboard/wiki/Uninstalling-OpenBangla-Keyboard) it first.

To install OpenBangla Keyboard, download the latest version for your platform from [Releases](https://github.com/OpenBangla/OpenBangla-Keyboard/releases). 

For detailed installation instructions and platform-specific guides, please refer to the [Installing OpenBangla Keyboard Wiki](https://github.com/OpenBangla/OpenBangla-Keyboard/wiki/Installing-OpenBangla-Keyboard).
