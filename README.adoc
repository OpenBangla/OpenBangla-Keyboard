*OpenBangla Keyboard* is a free, open-source, Unicode-compliant Bangla input method for Linux.
It includes Avro Phonetic with dictionary suggestions and autocorrect, the popular fixed layouts
(Probhat, Munir Optima, National/Jatiya, Bornona, Avro Easy) and typing automation tools.

If you have used https://www.omicronlab.com/avro-keyboard.html[Avro Keyboard] on Windows, you will feel right at home.

== Quick install

Open a terminal, paste this *one command*, and press kbd:[Enter]:

[source,bash,subs="attributes"]
----
bash -c "$(curl -fsSL {raw}/tools/install.sh 2>/dev/null || wget -qO- {raw}/tools/install.sh)"
----

That's it. The installer will:

. detect your Linux distribution, version and processor,
. download and install the right package from the newest OpenBangla Keyboard release,
. install the input method framework (IBus or Fcitx5) that suits your desktop,
. add *OpenBangla Keyboard* to your input sources.
  From version 3.0, OpenBangla Keyboard does this step itself; the installer only lends a hand on older versions.

It never replaces an input method you already use (for example Fcitx for Chinese or Japanese).

It asks for confirmation once, and for your password when it needs administrator rights.
When it's done, *log out and log back in*, then press kbd:[Super+Space] to switch between English and Bangla.

TIP: Want to see what it would do first? Add `--dry-run` at the end of the command:
`bash -c "$(...)" -- --dry-run`. All options are listed under <<installer-options>>.

[[installer-options]]
=== Installer options

Pass options after `--` at the end of the quick-install command, or run the script directly
(`bash install.sh [options]`):

[cols="1,3",options="header"]
|===
| Option | What it does

| `--ibus`       | Use the IBus framework (best on GNOME and Cinnamon)
| `--fcitx5`     | Use the Fcitx5 framework (best on KDE Plasma; needs a package with Fcitx5 support, which 3.0 and later have)
| `--no-setup`   | Only install the package; don't configure the desktop
| `--dry-run`    | Show what would happen without changing anything
| `-y`, `--yes`  | Don't ask for confirmation
| `--uninstall`  | Remove OpenBangla Keyboard
| `-h`, `--help` | Show help
|===

OpenBangla Keyboard is available in the Arch User Repository:

* `openbangla-keyboard` builds the package from source.
* `openbangla-keyboard-bin` installs the prebuilt release.

yay -S openbangla-keyboard-bin      # or: paru -S openbangla-keyboard-bin
----

=== Manual installation

Prefer to do it by hand? Download the package for your distribution from the
{repo}/releases[Releases page] and install it with your package manager:

[source,bash]
----
# replace the file name with the one you downloaded
sudo apt install ./downloaded-package.deb                          # Ubuntu, Debian and derivatives
sudo dnf install ./downloaded-package.rpm                          # Fedora
sudo zypper install --allow-unsigned-rpm ./downloaded-package.rpm  # openSUSE Tumbleweed (3.0+)
sudo pacman -U ./downloaded-package.pkg.tar.zst                    # Arch Linux
----

Then {repo}/wiki/Configuring-Environment[configure your desktop environment] to use it.

IMPORTANT: If you still have OpenBangla Keyboard *1.5.1 or older*,
{repo}/wiki/Uninstalling-OpenBangla-Keyboard[uninstall it] before installing a newer version.

== Using OpenBangla Keyboard

* *Switch language:* kbd:[Super+Space] on GNOME (IBus), or the shortcut set in your desktop's input settings.
* *Choose a layout:* click the OpenBangla icon in the top bar, or open *OpenBangla Keyboard* from your app menu.
* *Avro Phonetic:* type Bangla using English letters, for example `ami banglay gan gai` → `আমি বাংলায় গান গাই`.
  Suggestions appear as you type; press kbd:[Space] or kbd:[Enter] to accept.

== Features

Avro Phonetic::
* 100% compatible with the current Avro Phonetic scheme.
* Dictionary support suggests correctly spelled words as you type.
* Autocorrect for many commonly mistyped words.
* Commonly used English words (Facebook, download, ...) are written in Bangla even with their English spelling.
* Add and edit your own autocorrect entries.
* Preview window shows what you typed, right under the cursor.

Fixed keyboard layouts::
* Probhat, Munir Optima, Avro Easy, Bornona and National (Jatiya) included out of the box.
* Supports Avro Keyboard layout files (version 5).

Typing automation for fixed layouts::
* Automatic vowel forming.
* Old-style _Reph_.
* Traditional _-Kar_ joining.
* Automatic _Chandrabindu_ position fixing.

Convenience::
* Avro-style *Top Bar* for quick configuration.
* Built-in *Layout Viewer*.

== Troubleshooting

OpenBangla Keyboard doesn't show up in my input sources::
Log out and log back in (or restart) after installing. The input method framework only starts with a new session.
On GNOME, open *Settings → Keyboard → Input Sources → +* and look under *Bangla*.

I can't type Bangla in some applications::
Make sure IBus is running (`ibus-daemon -drx`) and that your session has `GTK_IM_MODULE=ibus`,
`QT_IM_MODULE=ibus` and `XMODIFIERS=@im=ibus` set. The installer writes these to
`~/.config/environment.d/90-openbangla-keyboard.conf`.

KDE Plasma on Wayland::
Open *System Settings → Keyboard → Virtual Keyboard* and select the input method framework you use.

"This script was not able to identify your OS distribution"::
Please {repo}/issues[open an issue] and include the output of `cat /etc/os-release`.
In the meantime, you can <<building-from-source,build from source>>.

For anything else, check the {repo}/wiki[Wiki] or ask on {repo}/discussions[GitHub Discussions].

== Building from source

=== Requirements

* GCC or Clang
* Rust (stable) and Cargo
* CMake and Make or Ninja
* Qt 5.5 or later
* IBus development files
* Zstandard (`zstd`) development files

Install them with one command for your distribution:

[cols="1,4",options="header"]
|===
| Distribution | Command

| Ubuntu / Debian
a| [source,bash]
----
sudo apt install build-essential rustc cargo cmake ninja-build libibus-1.0-dev qtbase5-dev qtbase5-dev-tools libzstd-dev
----

| Fedora
a| [source,bash]
----
sudo dnf install @buildsys-build rust cargo cmake ninja-build qt5-qtdeclarative-devel ibus-devel libzstd-devel
----

| Arch Linux
a| [source,bash]
----
sudo pacman -S base-devel rust cmake ninja qt5-base libibus zstd
----

| openSUSE
a| [source,bash]
----
sudo zypper install libQt5Core-devel libQt5Widgets-devel libQt5Network-devel libzstd-devel cmake ninja rust ibus-devel gcc gcc-c++
----

| Solus
a| [source,bash]
----
sudo eopkg install -c system.devel rust qt5-base-devel ibus-devel zstd-devel git
----
|===

=== Build and install

[source,bash]
----
git clone --recursive https://github.com/OpenBangla/OpenBangla-Keyboard.git
cd OpenBangla-Keyboard
cmake -B build -DCMAKE_INSTALL_PREFIX=/usr
cmake --build build
sudo cmake --install build
----

NOTE: This builds the IBus engine. Fcitx5 support is being developed in the
`develop` branch and will be part of OpenBangla Keyboard 3.0.
